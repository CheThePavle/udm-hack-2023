# Туристический комплекс «Мувыр»

## 1. Описание проекта

**«Мувыр»** — информационный веб-сайт туристического комплекса, предназначенный для знакомства посетителей с возможностями отдыха, проживания и проведения мероприятий.

Сайт позволяет ознакомиться с домиками для проживания, экскурсиями, развлечениями, новостями и информацией о туристическом комплексе. Посетители могут отправлять заявки на бронирование домиков, экскурсии и организацию свадебных мероприятий.

Для сотрудников предусмотрена административная панель, в которой после авторизации можно управлять информацией, размещённой на сайте, а также просматривать и обрабатывать поступившие заявки.

Проект разработан на **Laravel** с использованием базы данных **MySQL**.

## 2. Цели и задачи проекта

Основные задачи веб-сайта:

- Предоставление посетителям информации о туристическом комплексе.
- Демонстрация доступных вариантов проживания.
- Публикация информации об экскурсиях и развлечениях.
- Размещение новостей и информации о мероприятиях.
- Приём заявок на бронирование домиков и экскурсий.
- Приём заявок на организацию свадеб.
- Предоставление администраторам инструментов для управления содержимым сайта.

### 3.2. Работа с заявками посетителей

Сайт предусматривает несколько типов заявок:

**Бронирование домиков**

Посетитель может выбрать домик и отправить заявку, указав:

- Имя;
- Контактный телефон;
- Количество бронируемых мест (или домиков, согласно реализации формы);
- Дату и время заезда;
- Дату и время выезда.

Заявки сохраняются в таблице `house_request`.

**Заявка на экскурсию**

Посетитель может оставить заявку на выбранную экскурсию, указав имя и номер телефона. Заявки сохраняются в таблице `exc_request`.

**Заявка на организацию свадьбы**

Посетитель может отправить заявку на организацию свадебного мероприятия, указав имя и контактный телефон. Данные сохраняются в таблице `wedding_request`.

## 4. Административная панель

Административная часть предназначена для управления содержимым сайта и обработки поступающих заявок.

Доступ к административным маршрутам ограничен middleware `checkAuth`. Перед переходом в административную панель пользователь должен пройти авторизацию.

### 4.1. Авторизация и выход

| Метод | Маршрут | Назначение |
|---|---|---|
| POST | `/admin/user/auth` | Проверка данных пользователя и вход в систему |
| GET | `/admin/logout` | Выход из административной панели |

После успешной авторизации пользователь может перейти на главную страницу административной панели `/admin`.

### 4.2. Управление развлечениями

Администратор может просматривать список развлечений, открывать форму создания и редактирования, добавлять новые записи, изменять существующие и удалять их.

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/admin/funs` | Список развлечений |
| GET | `/admin/fun` | Форма добавления развлечения |
| GET | `/admin/change/fun/{id}` | Форма редактирования развлечения |
| POST | `/admin/fun` | Создание развлечения |
| PATCH | `/admin/fun` | Изменение развлечения |
| DELETE | `/admin/fun` | Удаление развлечения |

### 4.3. Управление новостями и мероприятиями

## 5. Структура базы данных

Для хранения информации используется реляционная база данных MySQL. Согласно SQL-дампу, в базе данных присутствуют следующие таблицы:

### 5.1. Таблица `user` — пользователи

Хранит учётные данные пользователей, имеющих доступ к административной части сайта.

| Поле | Тип | Описание |
|---|---|---|
| `id_user` | BIGINT | Уникальный идентификатор пользователя |
| `surname` | VARCHAR(255) | Фамилия |
| `name` | VARCHAR(255) | Имя |
| `patronymic` | VARCHAR(255) | Отчество |
| `phone` | VARCHAR(16) | Номер телефона |
| `login` | VARCHAR(255) | Логин |
| `password` | VARCHAR(255) | Хеш пароля |

Поля `phone` и `login` имеют ограничение уникальности.

### 5.2. Таблица `house` — домики

### 5.3. Таблица `house_request` — заявки на бронирование

## 6. Связи между таблицами

В SQL-дампе явно определены две связи с использованием внешних ключей:

1. **`house` → `house_request`**  
   Поле `house_request.id_house_request` ссылается на `house.id_house`. Один домик может быть указан в нескольких заявках.

2. **`excursion` → `exc_request`**  
   Поле `exc_request.id_exc_request` ссылается на `excursion.id_exc`. Одна экскурсия может быть указана в нескольких заявках.

Остальные таблицы в предоставленном SQL-дампе не имеют объявленных внешних ключей.

## 8. Используемые технологии

По предоставленным маршрутам и SQL-дампу можно определить следующие технологии и инструменты:

- **PHP** — серверный язык программирования.
- **Laravel** — PHP-фреймворк для построения веб-приложения.
- **MySQL** — реляционная система управления базами данных.
- **Blade** — шаблонизатор Laravel, предполагаемый для формирования страниц сайта.
- **Eloquent ORM / Query Builder** — возможные средства Laravel для работы с базой данных; конкретный способ работы с SQL в контроллерах по предоставленным материалам определить нельзя.
- **Middleware** — механизм ограничения доступа к административным маршрутам (`checkAuth`).

В SQL-дампе также указано окружение, в котором он был создан: PHP 7.4.33 и MySQL 8.0.33. Это сведения о среде создания дампа, а не подтверждение текущих версий проекта.

## 9. Общая логика работы проекта

1. Посетитель открывает сайт и просматривает доступные разделы.
2. При необходимости посетитель открывает карточку домика или экскурсии.
3. Посетитель заполняет форму и отправляет заявку.
4. Данные заявки сохраняются в соответствующей таблице базы данных.
5. Администратор открывает страницу авторизации и вводит свои учётные данные.
6. После успешной авторизации middleware `checkAuth` разрешает доступ к административным маршрутам.
7. Администратор просматривает поступившие заявки и управляет содержимым сайта.
8. После завершения работы администратор выходит из системы.

## 10. Итог

Веб-приложение «Мувыр» представляет собой сайт туристического комплекса с публичной информационной частью и административной панелью.

Публичная часть предназначена для информирования посетителей и приёма заявок на услуги. Административная часть обеспечивает управление пользователями, новостями, развлечениями, домиками и экскурсиями, а также просмотр и удаление поступивших заявок.
